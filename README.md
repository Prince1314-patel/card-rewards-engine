# Card Rewards Engine 🚀

A production-grade Fintech platform for AI-powered credit card reward optimization.

## Vision

The Card Rewards Engine helps users maximize credit card rewards by intelligently recommending the best card for each purchase.

## Quick Start

```bash
git clone https://github.com/Prince1314-patel/card-rewards-engine.git
cd card-rewards-engine
docker-compose up -d
```

Frontend: http://localhost:3000
Backend: http://localhost:8000
